#
# ทดสอบแล้วว่ารุ่น 4.13.0.92 กับ 5.0.0.93 ให้ผลเหมือนกันทุกบิต
#     รัน step3 + step4 ด้วยทั้งสองรุ่น แล้วเอาไฟล์ผลลัพธ์ 50 ไฟล์มาคำนวณ md5 รวม
#     ได้ e6f5a92a489d622417556fae8411c25a เท่ากันทั้งคู่
# เลือก 4.13.0.92 เพราะติดตั้งได้ทั้ง Python 3.9 และ 3.12
# ส่วน numpy รุ่นที่คู่กับ opencv 5 ต้องใช้ Python 3.11 ขึ้นไป ซึ่งตัดเครื่องที่ใช้ 3.9 ทิ้ง
#
# กับดักที่ต้องระวัง
#     opencv บน PyPI มีหลายแพ็กเกจที่ลงทับกันที่โฟลเดอร์เดียวกัน (site-packages/cv2/)
#         opencv-python              <- ใช้ตัวนี้
#         opencv-contrib-python
#         opencv-python-headless     <- ห้ามใช้ ไม่มีหน้าต่าง imshow ทำให้ step2 ใช้ไม่ได้
#         opencv-contrib-python-headless
#     ถ้าเผลอลงมากกว่า 1 ตัว ตัวที่ลงทีหลังจะทับตัวที่ลงก่อน แต่ pip ยังรายงานว่ามีทั้งคู่
#     เจอมาแล้วจริงใน Python ของระบบเครื่องที่ทำโปรเจกต์นี้
#         pip list บอกว่ามี opencv-python 4.10.0.84 และ opencv-contrib-python 5.0.0.93
#         แต่ cv2.__version__ ที่ import ได้จริงคือ 5.0.0
#     ถ้าเครื่องไหนเป็นแบบนี้ ให้ถอนออกให้หมดทุกตัวก่อน แล้วค่อยลงใหม่
#         pip uninstall opencv-python opencv-contrib-python opencv-python-headless
#         pip install -r requirements.txt
#     ต้องถอนให้หมดทุกตัว ไม่ใช่ถอนแค่ตัวที่ไม่ต้องการ
#     เพราะทั้งคู่ใช้โฟลเดอร์เดียวกัน ถอนตัวเดียวอาจลบไฟล์ที่อีกตัวต้องใช้ไปด้วย
